# 컨셉 — 몬스터 테이밍 덱빌더 (작업명 TBD)

> Soul Dungeon(STS식 덱빌딩 로그라이크, Flutter)의 **장르 엔진만** 계승한 **신규 모바일 게임**.
> 세계관·시그니처·콘텐츠·아트는 새로 설계. **덱빌딩 로그라이크 기조는 절대 유지.**

---

## 한 줄 컨셉

> **"네가 싸운 적이, 네 덱이 된다."**
> 몬스터 도감이 곧 카드풀. 어느 길로 가느냐가 곧 어떤 덱을 짤 거냐.

## 3 Pillars

1. **길들일까 죽일까** — 모든 전투가 전리품(처치) vs 카드풀(길들이기)의 선택
2. **맵이 곧 덱빌딩 조향** — 바이옴마다 서식 몬스터가 달라 루트 선택 = 덱 방향
3. **수집의 영속성** — 도감·업적으로 스타터/카드풀이 열리며 다음 런의 동기

---

## 주인공 & 스타터 (직업 개념 폐기)

- **주인공은 1명.** 원작의 "직업 9종" 개념은 **폐기**한다. 시작 덱은 직업이 아니라 **시작 몬스터**가 정한다.
- **런 시작 = 스타터 몬스터 선택** (포켓몬 스타터처럼). 고른 몬스터가 **초기 카드 풀 + 아키타입**.
- **일부 스타터는 업적 해금.** 초반엔 몇 종만 선택 가능 → 업적 달성/도감 진척으로 강하거나 특이한 스타터가 열림.
  - 원작의 "소울 상점/히든 직업 해금"을 **업적·도감 기반 스타터 언락**으로 대체.

---

## Core Loop

**Macro (1런 20~30분):** 스타터 몬스터 선택 → **분기 많은 맵**을 골라 나아가며 몬스터를 길들여 덱 성장 → 보스 → 사망/클리어 → **도감·업적 갱신** → 재도전
**Micro (1전투):** 조우 → 카드 플레이 → **제압(HP 저간)** → 길들이기 or 처치 → 보상(카드 드래프트)

---

## 시그니처 — 제압(Suppress) → 길들이기(Tame)  ✅ 프로토타입 완료

- 각 몬스터는 **제압 임계치**(기본 HP ≤ 25%). 죽이지 않고 임계치 이하로 낮추면 **[길들이기]** 가능.
- 길들이면: **도감 등록** + 그 몬스터가 **장착 가능 로스터**에 편입(→ 카드 풀 확장). 처치 보상은 포기.
- **빌드 정체성과 결합:** 버스트 덱은 과잉살상→길들이기 어려움 / 컨트롤·도트 덱은 조절 쉬움→테이밍 특화.
  → "어떤 덱을 짜느냐"가 "무엇을 모으느냐"를 좌우.

---

## 몬스터 = 덱 (확정: 장착 풀 + 개별 드래프트)

**STS의 얇고 날카로운 덱을 절대 깨지 않는다.** 몬스터를 잡을 때마다 카드가 우르르 들어오지 않는다.

- **장착 슬롯 2~3.** 장착한 몬스터들이 **"뽑을 수 있는 카드 풀"**을 정의한다(각 몬스터 4~6종).
- **덱은 STS처럼 한 장씩 드래프트.** 전투 승리/상점/이벤트 보상이 **장착 풀 + 무색 카드**에서 나온다.
- **카드 추가/제거/강화 전부 유지** → 덱은 여전히 손으로 깎아 얇게 만든다.
- **스타터 = 첫 장착 몬스터** → 시작 카드 풀. 런 중 새 몬스터를 길들여 **휴식 방에서 장착 교체** → 풀(=아키타입)이 바뀜.
- **타입 시너지:** 불/야수/언데드/기계… 장착 조합으로 아키타입 완성(불-도트덱, 무리소환덱 등).
- **진화 = 카드 업그레이드** (원작 340버전 업글 시스템 재사용).

> 요약: **풀은 넓히되(수집), 덱은 좁게(STS).** 몬스터=아키타입·카드풀, 덱=여전히 드래프트로 완성.

---

## 맵 = 덱빌딩 조향 (분기 대폭 확대)

이 게임의 진짜 훅. STS와 결정적으로 다른 지점.

- **바이옴별 서식 몬스터 풀.** 화산=불 몬스터, 늪=독 몬스터, 폐허=언데드… 지역마다 만날 몬스터(=길들일 카드)가 다름.
- **분기를 대폭 늘린다.** "불 카드가 필요하면 화산 루트로" → **길찾기 자체가 덱빌딩 결정**.
- 노드 유형(전투/엘리트/이벤트/상점/휴식/보스)은 유지하되, **어느 바이옴·어느 몬스터를 조우하느냐**가 핵심 선택.
- (설계 과제) 바이옴 정의 + 몬스터 서식 풀 + 분기 밀도. 원작 던전 생성기 확장 대상.

---

## 메타 = 도감 + 업적 언락

- **폐기:** 소울/유령/서술자왜곡/성향/엔딩.
- **도감(Bestiary):** 길들인 종 영구 기록. 진척이 스타터·카드풀 언락으로 이어짐.
- **업적:** 특정 조건(예: 특정 타입 5종 길들이기, 보스 몬스터 포획) → 새 스타터/특이 몬스터 해금.
- 런 간: 도감/업적에서 **스타터 로드아웃 선택**. 가챠 없음, 순수 플레이 수집.

## 덱 무결성 원칙 (기조 사수)

- 길들이기는 **카드를 직접 주지 않는다** — **뽑을 수 있는 풀만 넓힌다.**
- 덱에 카드가 들어가는 유일한 경로는 **드래프트(보상 선택)**. 제거·강화 상시 가능.
- 장착 슬롯 2~3으로 풀을 제한 → 무한 확장 방지.
- 목표는 언제나 **얇고 시너지 강한 덱.** 수집의 재미가 이걸 침범하지 않게.

## 정체성 (열린 항목)

- **이름/톤:** 미정 (다크판타지 유지 or 새 톤).
- **아트:** AI 생성 예정 — `docs/03_에셋_교체_가이드.md`의 swap 구조 위에 얹음. 직업 스프라이트 대신 **주인공 1 + 몬스터 다수**.

## 빌드 로드맵

1. ✅ **제압→길들이기 슬라이스** — 도메인+핸들러+버튼+씬 신호.
2. ✅ **길들이기 → 무브풀 카드 드래프트** (핵심 루프 완성) — `MonsterCards` 무브풀 데이터 레이어(1층 8종),
   길들이면 그 몬스터의 카드에서 **기존 카드보상 UI로 드래프트** → 덱 편입. 유닛 통과.
   - **린 덱 사수:** 우르르 안 주고 드래프트 1장. 미보유 우선.
   - 남은 ②: 로스터 영속(장착 슬롯 여러 몬스터의 풀 합산)은 ④ 도감과 함께.
3. **스타터 선택 화면** — 직업 선택을 스타터 몬스터 선택으로 교체. (업적 언락은 뒤에)
4. **장착 슬롯 UI** — 휴식 방에서 몬스터 교체 → 카드 풀 전환.
5. **도감·업적 메타** — 영속 저장 + 스타터 언락.
6. **바이옴 맵 확장** — 분기 밀도↑ + 지역별 서식 몬스터 풀.
7. 콘텐츠 채우기(몬스터→카드풀) + 밸런싱 → 아트 교체(AI) → 폴리시 → 스토어.

> 원작 도메인은 슬라이스①에서 **순수 확장**으로만 손댐. ②부터 직업→몬스터 전환이 본격화.
