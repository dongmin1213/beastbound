# 컨셉 — 몬스터 테이밍 덱빌더 (작업명 TBD)

> Soul Dungeon(STS식 덱빌딩 로그라이크)의 **장르 엔진만** 계승한 **신규 모바일 게임**.
> 세계관·시그니처·콘텐츠·아트는 백지에서 새로 설계.

---

## 한 줄 컨셉

> **"네가 싸운 적이, 네 덱이 된다."**
> 몬스터 도감이 곧 카드풀. 모든 전투가 곧 스카우트.

## 3 Pillars

1. **길들일까 죽일까** — 모든 전투가 전리품(처치) vs 카드/도감(길들이기)의 선택
2. **적 = 카드풀** — 길들인 몬스터의 스킬셋이 곧 덱. 도감을 채울수록 빌드 폭↑
3. **수집의 영속성** — 런을 넘어 도감이 쌓이고, 그게 다음 런의 동기 (모바일 리텐션)

---

## Core Loop

**Macro (1런 20~30분):** 스타터 몬스터 선택 → 탐험 → 몬스터 길들이며 덱 성장 → 보스 → 사망/클리어 → **도감 갱신** → 재도전
**Micro (1전투):** 조우 → 카드 플레이 → **제압(HP 저간)** → 길들이기 or 처치 → 보상

---

## 시그니처 — 제압(Suppress) → 길들이기(Tame)

**결정 확정: 제압 방식.** 미니게임 없이 순수 전투 의사결정.

- 각 몬스터는 **제압 임계치**(기본 HP ≤ 25%)를 가진다.
- 적을 **죽이지 않고** 임계치 이하로 낮추면 → **[길들이기]** 선택 가능.
- 길들이면: 전투 종료 + 몬스터 **도감 등록** + **카드 패키지** 획득. (처치 보상은 포기)
- 처치하면: 일반 보상 (골드/카드 강화/유물).

### 빌드 정체성과의 결합 (핵심 재미)
- **버스트/고뎀 덱** → 과잉살상 위험 → 길들이기 어려움 → "처치 특화"
- **컨트롤/도트(독·화상) 덱** → 데미지 조절 쉬움 → "테이밍 특화"
- → 덱 성향이 "무엇을 모으느냐"를 좌우. 공짜로 생기는 전략 축.

### 리스크 설계
- 임계치까지 낮춘 뒤 마무리를 미루면 적은 **계속 행동**(피해 누적) → 길들이기엔 대가가 따름.
- 엘리트/보스: 임계치 낮거나 특수 조건 → 길들이면 **희귀 대박**.
- (열림) "제압" 상태에서 적 발버둥(도주 확률)·전용 길들이기 카드 등은 밸런싱 단계에서.

---

## 몬스터 = 덱 (파티배틀러가 되지 않게)

**덱은 여전히 "한 벌의 카드".** 몬스터를 파티로 세워 각자 턴 주는 게 아님.

- **장착 슬롯 2~3.** 장착 몬스터들의 카드 패키지(각 4~6장)가 **합쳐져 덱**.
- 나머지 길들인 몬스터는 **벤치**(도감엔 있으나 이번 런 미사용). 휴식 방에서 교체.
- 화면상 내 편에 **리드 몬스터**가 서지만(포켓몬식 배틀씬), 전투는 **카드로** 굴러감 → STS 엔진 유지.
- **타입 시너지** 빌드: 불/야수/언데드/기계… 타입을 모으면 아키타입 (예: 불-도트덱, 무리소환덱).
- 개별 카드 보상(상점/이벤트)도 병행 → 몬스터=청크 단위, 카드=미세 조정.

## 진화 = 카드 업그레이드 (기존 시스템 재사용)

몬스터가 런 중/런 간 진화 → 카드가 강화판으로. 원작의 **카드 업그레이드 시스템(340버전)**에 그대로 매핑.

## 메타 = 도감 (Bestiary)

- 소울/유령/서술자왜곡 시스템은 **폐기** → **도감**으로 교체.
- 종 최초 길들이기 → 도감 등록 → **스타터 해금** + 소량 영구 보너스.
- 런 간: 도감에서 **스타터 로드아웃 선택**. "저 보스 몬스터 길들이기"가 다음 런 동기.
- 가챠 없음, 순수 플레이로 수집.

## 재사용 vs 신규 (buildable 체크)

| 요소 | 처리 |
|------|------|
| 카드/덱/턴/AP/기세/상태효과/적 AI | **STS 엔진 그대로** |
| 런/층/방/세이브/유물·이벤트 프레임워크 | 그대로 |
| 카드 업그레이드 | 진화로 재사용 |
| 적 40종 | 길들이기 대상(도감)으로 재활용 → 카드 패키지화 |
| Flame 전투 씬 | 이미 만듦 (포켓몬식) |
| 소울/유령/왜곡/성향/엔딩 | **폐기** |
| **신규 시스템 (딱 3개)** | ① 제압→길들이기 ② 로스터/장착 슬롯 ③ 도감 화면 |

> 새로 짤 게 **3개**뿐. 나머진 다 있음.

## 정체성 (열린 항목)

- **이름:** 미정. (다크판타지 테이밍 톤 — 예: "정령/사역/포식" 계열 키워드)
- **아트:** AI 생성 예정. `docs/03_에셋_교체_가이드.md`의 swap 구조 위에 얹음.
- **톤:** 다크판타지 유지 여부 or 새 톤 — 이름과 함께 결정.
