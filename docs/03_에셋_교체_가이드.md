# 에셋 교체 가이드 — "그림만 갈아끼우면 되게"

> 목표: AI(GPT 등)로 새 캐릭터 아트를 만든 뒤, **파일 드롭 + 한 파일 수정**만으로
> 전투 씬에 반영되게 한다. 씬/애니메이션 코드는 건드리지 않는다.

---

## 교체 지점은 딱 한 곳

모든 전투 스프라이트 해석은 **`lib/presentation/screens/game/combat/flame/combat_sprites.dart`** 를 거친다.
새 아트를 붙일 때 수정하는 파일은 원칙적으로 **이 파일 하나뿐**이다.

```dart
class CombatSprites {
  static ActorSprites enemy(String id) => ActorSprites(
    idle:   ...,   // ← 지금은 원작 초상화 재활용
    attack: ...,   // ← AI 아트 나오면 여기만 채움
    hurt:   ...,
    death:  ...,
  );
  static ActorSprites job(String? jobId) => ActorSprites( idle: ... );
}
```

`CombatActor`는 **있는 프레임만 자동으로 사용**한다:
- `attack` 있으면 → 공격 시 그 프레임. 없으면 → idle + 런지 트랜스폼.
- `hurt` 있으면 → 피격 시 그 프레임. 없으면 → idle + 붉은 플래시.
- `death` 있으면 → 사망 프레임. 없으면 → idle + 디졸브.

즉 **idle 한 장만 갈아끼워도** 즉시 반영되고, 나중에 상태 프레임을 추가해도 코드 변경 0.

## 스프라이트 사양 (AI 프롬프트 기준)

| 항목 | 값 |
|------|-----|
| 스타일 | 다크 판타지 SD 픽셀아트 (원작 `docs/ART.md` 팔레트/비율 계승) |
| 캔버스 | 캐릭터 **96×96 이상** 권장 (씬에서 크게 표시 — 기존 24~48px는 작음) |
| 배경 | **완전 투명**(알파). 반투명 픽셀 금지(글로우 예외) |
| 방향 | **오른쪽을 바라보게** 그린다 (적은 코드가 좌우 반전) |
| 발 위치 | 캔버스 **하단 중앙**에 발이 닿게 (앵커 bottomCenter) |
| 상태(선택) | idle / attack(찌르기·앞으로) / hurt(움찔·뒤로) / death(쓰러짐) |
| 스케일링 | NEAREST 전제 — 안티앨리어싱 없이 선명하게 |

> 최소 요구: **idle 1장**. 나머지는 코드가 트랜스폼으로 대체하므로 나중에 채워도 됨.
> 우선순위: idle 전체 → 자주 보는 1층 적 + 시작 직업 attack/hurt → 보스 death.

## 권장 파일 배치

새 아트는 원작 에셋과 섞이지 않게 **별도 디렉토리**에 둔다:

```
assets/pixel_art_v2/
  jobs/
    warrior/idle.png   (attack.png hurt.png death.png ...)
    saint/idle.png
    ...
  enemies/
    enemy_goblin/idle.png (attack.png ...)
    enemy_slime/idle.png
    ...
  bosses/
    boss_slime_king/idle.png ...
```

그리고:
1. `pubspec.yaml`의 `flutter/assets:`에 새 디렉토리 등록
2. `combat_sprites.dart`에서 경로를 새 규칙으로 변경 (아래 예시)

```dart
// combat_sprites.dart
static String _v2(String rel) => 'assets/pixel_art_v2/$rel.png';

static ActorSprites enemy(String id) => ActorSprites(
  idle:   _v2('enemies/$id/idle'),
  attack: _v2('enemies/$id/attack'),   // 파일 없으면 null 처리(아래 참고)
  hurt:   _v2('enemies/$id/hurt'),
  death:  _v2('enemies/$id/death'),
);
```

> 파일이 아직 없는 상태 프레임은 경로를 `null`로 두거나, 존재 여부 폴백을 넣는다.
> (없는 경로를 지정하면 로드 시 에러 → 있는 것만 지정할 것.)

## 캐릭터 ID 목록 (매핑 키)

`combat_sprites.dart`가 받는 id는 게임 내부 식별자다.

- **직업(12):** `warrior` `saint` `sage` `assassin` `guardian` `wanderer` `reaper` `illusionist` `harmonist` (+ 히든 3)
  - 매핑표: `lib/presentation/theme/pixel_art_assets.dart` `_jobSprites`
- **적(40):** `enemy_goblin` `enemy_slime` `enemy_rat` … (층별)
  - 매핑표: `_enemySprites`
- **보스(15):** `boss_*`
  - 매핑표: `_bossSprites`

> id는 `EnemyCombatData.id` / `PlayerRunState.currentJobId`와 동일하다.
