# 이벤트 & 방 레퍼런스

방 8종 + 이벤트 31종(기본 19 + 히든 12) + 직업 변형 6종 + NPC 시스템 + 유령 NPC.

---

## 총괄 요약

| 방 타입 | 핵심 | 보상 |
|---------|------|------|
| combat | 일반 몬스터 | 골드 10 + 카드 보상 |
| elite | 강화 몬스터 | 골드 25 + 유물 + 카드 보상 |
| event | 내러티브 선택지 | 골드/HP/성향/카드 (이벤트별) |
| mystery | 가중치 랜덤 결과 | 가변 |
| shop | 카드/아이템 구매, 카드 제거 | — |
| npc | 대화/거래 | 골드/축복/보급품 |
| rest | 회복/강화 택 1 | HP 15% 회복 OR 최대HP +3 |
| boss | 다단계 전투 → 선택지 | 골드 30 + 엔딩 누적 |

---

## 맵 생성 규칙

- **구조:** DAG (방향 비순환 그래프), StS 스타일
- **분기:** 레이어당 2~4 노드 (branch_factor_min=2, branch_factor_max=4)
- **층별 노드 수:** 1층 16 → 2층 18 → 3층 20 → 4층 22 → 5층 24
- **예상 뎁스:** 6~9, 경로 길이 7~10
- **고정 배치:** 시작=combat, 마지막=boss
- **엘리트:** depth 2+ 에서 1~3개 배치
- **경로 보장:** 모든 경로에 shop + event/npc 최소 1개
- **나머지:** combat(60%), mystery(20%), event(20%) 가중 랜덤

## 상점

- **아이템:** 3~5개 (축복 45%, 보급품 40%, 유물 15%)
- **카드:** 1~2장 구매 가능
- **카드 제거:** 항상 35G
- **가격 스케일링:** base × 1.2^(층-1)
- **희귀도 가중:** Common 55%, Rare 30%, Legendary 10%, Cursed 5%

## NPC (3종 + 유령)

### 일반 NPC (3종)

| 타입 | 가중치 | 보상 |
|------|--------|------|
| 상인 (Trader) | 40% | 축복/보급품 판매 (2~3개) |
| 현자 (Sage) | 30% | 대화 + 골드 14 |
| 방랑자 (Wanderer) | 30% | 대화 + 골드 14 |

상인: 이름 10종, 인사 10종, 대사 5종
현자: 이름 10종, 인사 10종, 대사 10종
방랑자: 이름 10종, 인사 10종, 대사 5종

### 유령 NPC

NPC 방 진입 시 유령 풀에서 먼저 스폰 시도. 유령 등장 시 일반 NPC 생략.

**스폰 조건:** 2런차 2층 100% / 3런차+ 30%

**반응 레벨:** 현재 성향과 유령 성향의 코사인 유사도 (familiar ≥0.7, curious ≥0.3, distant <0.3)

| 레벨 | 선택지 |
|------|--------|
| familiar | 이야기를 나눈다 / 지식을 나눠받는다 / 겨뤄본다 / 작별을 고한다 |
| curious | 이야기를 나눈다 / 겨뤄본다 / 작별을 고한다 |
| distant | 조심스럽게 다가간다 / 도발한다 / 무시하고 지나간다 |

- **비전투 선택:** 보상(HP/기세/골드) + 리스크(HP 손실/기세 리셋) 확률 판정
- **전투 선택 (`ghost_fight`):** 유령을 엘리트 적으로 변환 → 카드 전투. 승리 보상은 유령 직업 카드

상세: `META.md` 유령 NPC 섹션, `ENEMIES.md` 유령 전투 섹션
