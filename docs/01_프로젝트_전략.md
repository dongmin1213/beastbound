# Soul Dungeon: Reforged — 프로젝트 전략

> 원작 `soul-dungeon`(텍스트 카드 로그라이크, Flutter, v1.0.5, 사실상 완성작)을
> **그래픽 중심으로 업그레이드한 별도 게임**으로 출시하기 위한 전략 문서.

---

## 1. 왜 되는가 — 검증된 게임 + 재사용 가능한 두뇌

원작은 이미 **재미가 검증된 완성작**이다. 리메이크의 리스크가 "재미있나?"에서
"보기 좋게 만들 수 있나?"로 줄어든다. 이건 리메이크에서 최고의 출발점이다.

결정적으로, 원작은 `core ← domain ← presentation` 클린 아키텍처라
게임 로직(domain, 2.8만 줄)이 UI와 **완전히 분리**돼 있다.
(domain은 `flutter_bloc`/`foundation`/`services`만 의존, material/widgets 결합 0)
→ **로직은 통째로 재사용하고, "그래픽을 넣는" presentation만 다시 짜면 된다.**

---

## 2. 코드 전략 — 포크 후 presentation 교체

```
soul-dungeon (원작, 그대로 보존 — 스토어 유지)
   └─ 통째 복제 → soul-dungeon-reforged (신규)
         ├─ lib/core/     ← 그대로 (인프라)
         ├─ lib/domain/   ← 그대로 (검증된 두뇌, 손 안 댐)
         ├─ lib/audio/    ← 그대로 + BGM 확장
         └─ lib/presentation/ ← 그래픽 중심으로 갈아엎음 ★
```

원작은 손대지 않아 출시본이 안전하다. 신규 레포에서 presentation만 교체한다.

---

## 3. 그래픽 수준 — "연출형 전투 씬 + 텍스트 정체성 유지"

풀 2D 액션(캐릭터가 돌아다니는 Skul식)은 **함정**이다. 장르가 바뀌고
(물리/충돌/레벨디자인 필요) 2.8만 줄 두뇌의 절반이 무의미해진다.
반대로 일러스트만 얹으면 "업그레이드"로 안 보인다.

**스위트 스팟 = 전투를 살아있는 씬으로:**

| 지금 (텍스트) | Reforged (연출) |
|---|---|
| "고블린이 8 피해" | 고블린이 달려들어 베고 + 화면 흔들림 + 데미지 팝 + 피격 플래시 |
| 카드 = 텍스트 로그 | 카드에서 슬래시/투사체 VFX가 적에게 명중 |
| 방어 = 숫자 | 방패 쉬머, 버프 = 오라 파티클 |
| 기세 = 숫자 | 차오르는 게이지, 티어 전환 시 발광·펄스 |
| 적 의도 = 텍스트 | 머리 위 의도 아이콘 |

스프라이트 4상태(idle 호흡 / attack 런지 / hurt 플래시+넉백 / death 디졸브)만 있으면 씬이 산다.

> **"서술자 왜곡"은 절대 버리지 않는다.** 이게 이 게임의 정체성이자
> 여타 Slay the Spire 클론과 차별화되는 유일한 무기다. 오히려 그래픽으로 강화한다
> (왜곡 발동 시 채도 down + 텍스트 글리치 + 스프라이트 잔상).

## 4. 엔진 — Flutter 유지 + 전투 씬만 Flame 임베드

- UI/메뉴/상점/이벤트/이벤트 = **Flutter 위젯** 그대로 (선언형이 강한 영역)
- **전투 씬만 `GameWidget`(Flame)으로 임베드** — 스프라이트 애니·파티클·화면흔들림 같은
  타이트한 프레임 루프는 Flutter 선언형보다 Flame 게임루프가 압도적으로 유리
- Flame은 Flutter **위젯으로 박히므로** 나머지 앱과 자연스럽게 공존
- 전면 엔진 교체는 반대(두뇌를 다 버리게 됨)

상세 통합 방법은 → [`02_전투씬_통합지도.md`](02_전투씬_통합지도.md)

## 5. ⚠️ 스토어 규정 — 반드시 알 것

Apple 심사 가이드 **4.3(스팸)** / Google 유사앱 정책상, 같은 개발자가
거의 동일한 앱 2개를 올리면 리젝된다. "리스킨"만으론 안 되고 **의미 있는 차별화**가 필요하다.
위 연출형 전면 개편이면 충분히 다른 게임으로 인정되지만, 안전하게 하려면:

- 새 이름·아이콘·스토어 스크린샷 (당연)
- 최소 하나의 **새 시스템/모드** 추가 (예: 신규 직업 1, 신규 층 테마, "빠른 전투 모드")
- 원작 무료화 + Reforged 프리미엄 전략도 고려
