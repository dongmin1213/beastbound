# Soul Dungeon - Game Design

텍스트 기반 카드 로그라이크 RPG. "선택이 곧 힘이 되는 게임."

---

## 3 Pillars

1. **선택의 무게** — 모든 선택이 빌드 경로 + 서사 분기에 동시 영향
2. **기억하는 던전** — 유령 NPC, 기억 조각, 소울로 런 간 연결
3. **텍스트의 힘** — 텍스트 속도/스타일/신뢰도 자체가 게임 메카닉

---

## Core Loop

**Macro (1런 20~30분):** 준비 → 탐험 → 사망 또는 클리어 → **런 요약** → 타이틀 → 재도전
**Micro (1방 1~3분):** 방 진입 → 서술 → 선택 → 결과 → 보상 → 다음 방

### 런 요약 (Run Summary)

모든 런 종료 시점(사망/클리어)에 SKUL 스타일의 **여정의 기록** 표시:
- 직업, 도달 층수, 덱 크기(제거 포함), 축복/유물/저주 수, 소지 골드
- 보스 선택 기록 (층별 선택 이력)
- 획득 소울 표시
- 적용 지점: 카드 전투 사망, 텍스트 전투 사망, 보스 승리/엔딩, 이벤트 방 사망, 미스터리 방 사망

---

## 전투 턴 흐름

```
1. 턴 시작: 블록 초기화, 상태 효과 틱, 카드 5장 드로우
2. 적 의도 표시 (일반: 공개 / 엘리트: 2턴간 ??? / 보스: 항상 공개)
3. 플레이어: AP 소모하며 카드 플레이 (순서 자유, 여러 장 가능)
4. 턴 종료: 남은 손패 버림, 적 행동 실행
5. HP 체크 → 계속 or 종료
```

- 시작 덱: 공통 7장으로 시작 → 직업 분화 시 직업 5장 추가 = 12장. 분화 전 획득 카드(상점/보상) 보존
- 매 턴 5장 드로우
- AP는 기세 티어(Low 2 / Mid 3 / High 4)로 결정
- 블록은 턴 시작 시 0 초기화 (축복으로 유지 가능)
