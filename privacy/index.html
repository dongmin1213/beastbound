Soul Dungeon 개인정보 보호정책

최종 업데이트: 2026년 3월 1일

Soul Dungeon(이하 "앱")을 이용해 주셔서 감사합니다. 본 개인정보 보호정책은 앱이 사용자 정보를 어떻게 처리하는지 설명합니다.

1. 수집하는 정보

Soul Dungeon은 어떠한 개인정보도 수집하지 않습니다. 앱은 인터넷 연결 없이 완전히 오프라인으로 동작하며, 외부 서버로 데이터를 전송하지 않습니다.

2. 기기 내 저장 데이터

앱은 게임 진행 상태를 사용자의 기기에만 저장합니다:

  • 게임 세이브 데이터 (런 진행 상황, 소울 포인트 등)

이 데이터는 기기 밖으로 전송되지 않으며, 앱 삭제 시 함께 삭제됩니다.

3. 제3자 서비스

Soul Dungeon은 광고, 분석, 소셜 로그인 등 제3자 서비스를 일체 사용하지 않습니다.

4. 아동 개인정보 보호

본 앱은 개인정보를 수집하지 않으므로 만 14세 미만 아동의 정보도 수집되지 않습니다.
